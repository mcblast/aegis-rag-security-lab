# Phase 02 - Threat Model

## Purpose

Phase 02 defines the initial AI security threat model for Aegis RAG Security Lab after the keyword, semantic, and GraphRAG retrieval paths have been implemented.

The goal of this phase is to identify assets, actors, trust boundaries, retrieval-specific attack surfaces, attack paths, and control gaps before building adversarial test cases or defensive controls in later phases.

Phase 02 is an analysis phase. It does not attempt to fix every identified issue. Instead, it creates the architectural map that later phases use for testing, hardening, governance, and monitoring.

---

## Phase Scope

### Included

- AI threat surface analysis
- Asset identification
- Actor identification
- Trust boundary mapping
